# Mehdi CHIBANI — Portfolio

Personal site for Mehdi Chibani, senior React Native & Flutter consultant.

Plain **HTML, CSS and JavaScript**. No build step.

## Open locally

```bash
cd ~/Developer/mehdi-chibani-portfolio
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## What’s on the home page

- Hero matching the navy + electric-blue visual (photo, stack, CTAs)
- About + toolbox
- Experience (NEOSYS / ONCF Voyages, Aramobile / My Wafa, Pass Jeunes, Wafa Santé)
- Internships
- Apps live on Google Play
- Personal projects (FinCount, BourseIQ, …)
- Education
- Contact

English / French toggle (saved in the browser). Light / dark theme.

The **case-study details page** (clients, screenshots, deep dives) is the next step. Cards currently show “Case study soon”.
